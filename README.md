# UCUP Flutter Demo

Bu loyiha UCUP ilovasining frontend/demo versiyasi.

## Ishga tushirish
1. Flutter SDK o'rnating.
2. Terminalda loyiha papkasiga kiring.
3. `flutter pub get`
4. `flutter run`
5. APK uchun: `flutter build apk --release`

APK:
`build/app/outputs/flutter-apk/app-release.apk`

## Muhim
Bu demo:
- loginni haqiqiy serverga ulamaydi;
- reklama o'rniga demo tugmasidan foydalanadi;
- UC balansini faqat qurilma ichida vaqtincha o'zgartiradi;
- haqiqiy PUBG/KRAFTON UC tarqatish API'siga ulanmagan;
- referal ham demo.

Haqiqiy mahsulot uchun backend, autentifikatsiya, ma'lumotlar bazasi, reklama SDKsi, fraud/anti-abuse himoyasi va qonuniy/ruxsat etilgan UC tarqatish mexanizmi alohida qo'shilishi kerak.
